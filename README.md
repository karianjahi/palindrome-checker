A simple and interactive **Palindrome Checker** built with **HTML, CSS,
and JavaScript**.\
It determines whether a word, number, or phrase reads the same forward
and backward.

## 🌐 [Live Demo](https://karianjahi.github.io/palindrome-checker/)


------------------------------------------------------------------------

## ✨ Features

-   🔎 Checks if text is a palindrome
-   🧹 Ignores punctuation, spaces, and capitalization
-   ⌨️ Works with **Enter key** and **Button click**
-   🎨 Clean, responsive UI styling
-   🚫 Alerts when input is empty

------------------------------------------------------------------------

## 🧠 How It Works

1.  User enters text.
2.  Non-alphanumeric characters are removed.
3.  The cleaned string is converted to lowercase.
4.  The string is reversed.
5.  Both versions are compared.
6.  Result is displayed dynamically on the page.

------------------------------------------------------------------------

## 🚀 Live Behavior Example

Input:

    A man, a plan, a canal: Panama

Output:

    A man, a plan, a canal: Panama is a palindrome
